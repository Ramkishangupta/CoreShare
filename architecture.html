📤 Job Submission

User uploads Dockerfile, selects GPU/CPU resources, and submits to the platform via web interface.

🔍 Resource Matching

Orchestrator finds available worker with matching GPU/CPU specs using the Worker Manager.

🐳 Docker Execution

Worker builds image from Dockerfile and runs container with allocated GPU/CPU resources.

💰 Billing & Credits

System calculates cost based on resource usage time and deducts from user's credit balance.

✨ Key Features

🔐 Secure Authentication

JWT-based authentication, bcrypt password hashing, role-based access control

⚡ Real-time Updates

WebSocket connections for live job status, log streaming, and worker heartbeat monitoring

🎯 Smart Resource Allocation

Automatic worker selection based on GPU/CPU requirements with validation at multiple layers

💰 Usage-based Billing

Per-minute billing for GPU and CPU usage with automatic credit deduction

🔒 Container Isolation

Docker security features: network isolation, resource limits, read-only filesystem options

📊 Job Monitoring

Real-time logs, resource usage tracking, job history, and detailed billing reports

🔄 Auto-reconnection

Workers automatically reconnect to orchestrator with exponential backoff on connection loss

📈 Scalable Queue

Bull queue with Redis for handling high job throughput and retry mechanisms
